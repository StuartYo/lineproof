Is this service line lead? Show the record that says so.

US water utilities must sort every service line into Lead, Galvanized requiring replacement, Non-lead or Unknown by November 1, 2027. LineProof reads the old tap cards, permits and field notes, quotes the line behind each fact, and applies the federal rules in plain code.

    How it decides

    The model reads

    Gemma 4 E2B runs on your own GPU through WebLLM. It returns facts only: which side of the line, which material, installed or removed, the date, and the exact words from the record. It never picks the category.

    Code checks

    A fact is dropped if its quote is not in the record, if the quote does not name the material claimed, or if a "lead" quote says "no lead". Staff memory, customer reports and predictions are set aside unless the state approved them.

    Rules decide

    Twelve rules from 40 CFR 141.2 and 141.84 and EPA's inventory guidance, written as code and tested. Each step on screen names its rule. When records conflict, it takes the cautious answer EPA recommends and says what would settle it.

    Rules as of the Lead and Copper Rule Improvements (89 FR 86418, October 30, 2024; eCFR read November 2026). State rules differ on ban dates and which sources count; pick the state setting on each line. LineProof helps staff prepare an inventory for state review. It does not replace a field check, and it is not legal advice.

    MIT license. All addresses, records and the district are made up. The expected answers for the "EPA & state examples" come from the documents linked on each case.
