Is this service line lead? Show the record that says so.

Every US water system must sort each service line into Lead, Galvanized requiring replacement, Non-lead or Unknown by November 1, 2027. Pick a line: Gemma 4 reads its old records and quotes each fact, then twelve federal rules in plain code decide.

Where the model matters. Keyword matching reads "Lead inspector" as a lead pipe (400 Upland Ave) and drops a lead pipe when the same sentence also mentions a lead gooseneck (1507 Marlow Ave, blind holdout). Gemma reads both right. Across all 52 test cases the two disagree on 12: Gemma is right on 10, keywords on 1.

    How it decides

    The model reads

    Gemma 4 E2B runs on your own GPU through WebLLM. It returns facts only: which side of the line, which material, installed or removed, the date, and the exact words from the record. It never picks the category.

    Code checks

    A fact is dropped if its quote is not in the record, if the quote does not name the material claimed, or if a "lead" quote says "no lead". Staff memory, customer reports and predictions are set aside unless the state approved them.

    Rules decide

    Twelve rules from 40 CFR 141.2 and 141.84 and EPA's inventory guidance, written as code and tested. Each step on screen names its rule. When records conflict, it takes the cautious answer EPA recommends and says what would settle it. The "rules in the prompt" comparison gets the same rules as 11 written points: R06 and R07 share one point, R11 is part of the combine order, and one point says a galvanized utility side is non-lead.

    Rules as of the Lead and Copper Rule Improvements (89 FR 86418, October 30, 2024; eCFR read November 2026). State rules differ on ban dates and which sources count; pick the state setting on each line. LineProof helps staff prepare an inventory for state review. It does not replace a field check, and it is not legal advice.

    MIT license. All addresses, records and the district are made up. The expected answers for the "EPA & state examples" come from the documents linked on each case.
